## Authentication

All API endpoints are authenticated using `Authorization` header on the request. There are 3 ways of authentication: `Bearer`, `Oauth` and `Apikey`.

**Bearer** - JWT token used for personal projects, found in [`https://streamelements.com/dashboard/account/channels`](https://streamelements.com/dashboard/account/channels)

**Oauth** - Token provided after oAuth authentication. More info in [https://dev.streamelements.com/docs/api-docs/cd02cda5171ea-o-auth2](https://dev.streamelements.com/docs/api-docs/cd02cda5171ea-o-auth2)

**Apikey** - Token provided for use in custom widgets, visible during onWidgetLoad, key `obj.detail.channel.apiToken`

<Note>
  Not all endpoints accept all types of authentication. Most of them work with Bearer, some with Oauth and a few with Apikey. When trying to use a non-supported authentication, you will receive a `403 - Forbidden`.
</Note>
